# Tension Theory — Social System Analysis

## Purpose

Use Tension Theory as a lens for analyzing social systems — organizations, communities, institutions, conflicts.

Society is not a collection of individuals.
It is a persistent relational configuration maintained through continuous local tension management across nodes with bounded memory and asymmetric information access.

---

## Vocabulary

**Social structure:** A persistent form — a configuration of states and relations stable under local updates. Exists because tension gradients are locally balanced, not because it was designed.

**Role:** A stable node configuration within a social graph; defines what a node knows, what it can do, and what tension it is expected to manage.

**Power:** Privileged access to high-tension edges — the ability to influence the update rules of adjacent nodes without being obligated to absorb their tension.

**Institution:** A high-memory stable configuration with enforcement mechanisms; costly to update, redistributes tension broadly when it changes.

**Culture:** Distributed persistent state shared across many nodes; shapes local update rules without central coordination. Changes slowly because it is stored in many nodes simultaneously.

**Trust:** A low-tension edge between nodes; updates flow with low cost and minimal verification.

**Conflict:** A high-tension edge resisting update; accumulated incompatible states between nodes that neither can resolve locally.

**Norm:** A shared update constraint that bounds acceptable state transitions within a group; maintained by distributed enforcement.

**Reputation:** Compressed state history stored in the graph about a node; influences its tension profile with others without direct interaction.

**Social change:** A cascade of updates following a new tension gradient across the graph — triggered when accumulated tension exceeds the cost of restructuring.

**Resilience:** A system's capacity to absorb local tension spikes without triggering cascading updates across the graph.

**Fragility:** High coupling between nodes such that local tension propagates rapidly and broadly — small updates produce large cascades.

## Analysis Algorithm

### Step 1 — Map the Social Graph

Identify:

- Actors / groups / institutions (nodes)
- Relationships / obligations / channels (edges)
- Information flows (who communicates with whom, about what)

Note which edges carry high vs. low tension.

---

### Step 2 — Determine Memory Distribution

For each relevant actor ask:

- What information do they hold?
- What is their historical memory (what past states shape their current behavior)?
- Where is knowledge asymmetric across the graph?
- Who holds information that others need but cannot access?

---

### Step 3 — Detect Tension Sources

Search for:

- Role conflicts (a node is expected to perform incompatible updates)
- Resource scarcity (constrained paths forcing competition between nodes)
- Norm violations (updates that exceed accepted constraints, raising tension broadly)
- Unacknowledged state changes (one part of the graph has updated; others haven't registered it)
- Deferred grievances (accumulated tension with no available update path — pressure building)

---

### Step 4 — Analyze Update Pathways

For available tension resolution mechanisms ask:

- Negotiation: mutual state update, low cost if trust is high
- Enforcement: forced update via power differential, creates resentment (new tension)
- Exit: node decouples from the graph, tension is removed but graph topology changes
- Reform: high-cost update to institutional rules, reduces future tension gradients
- Collapse: configuration becomes unstable, cascading restructuring

For each pathway: what is the cost? who bears it? what new tensions does it create?

---

### Step 5 — Classify System Dynamics

Classify:

- Stable (tensions managed locally, structure persistent)
- Adaptable (update pathways available, tension resolved before accumulating)
- Fragile (high coupling, norms under stress, low trust)
- Near collapse (blocked update paths, high accumulated tension, cascade risk)
- Transforming (active restructuring — roles, institutions, or graph topology changing)

---

## Output Format

Always produce:

1. Social graph (actors, key relationships, power gradients)
2. Tension map (high-tension edges, blocked update paths)
3. Memory asymmetry map (who knows what others don't)
4. Available update pathways and their costs
5. Stability classification
6. Predicted evolution and likely cascade paths
