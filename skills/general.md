# Tension Theory — General System Analysis

## Purpose

Use Tension Theory as a lens for understanding any system.

Never analyze systems as static objects.
Always analyze them as evolving networks of constrained states.

---

## Analysis Algorithm

### Step 1 — Define the System Graph

Identify:

- Nodes
- Relationships
- Information flows

---

### Step 2 — Determine Local Constraints

For each relevant node ask:

- What does it know?
- What does it ignore?
- What can it remember?
- What are its limitations?

---

### Step 3 — Detect Tensions

Search for:

- Contradictory goals
- Resource scarcity
- Information asymmetry
- Delayed feedback
- Accumulated unresolved changes

---

### Step 4 — Analyze Possible Updates

For every possible transition evaluate:

- Cost
- Information required
- Time needed
- Side effects
- New tensions created

---

### Step 5 — Determine System Dynamics

Classify:

- Stable
- Adaptable
- Fragile
- Near collapse
- Transforming

---

## Output Format

Always produce:

1. System graph
2. Tension map
3. Memory limitations
4. Update pathways
5. Stability assessment
6. Predicted evolution
