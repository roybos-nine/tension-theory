01 — THE IDEA

Physics describes what happens. This asks how reality runs.

Our best theories use infinite-precision fields, continuous space-time, and global wave functions. They predict beautifully — but they say nothing about the mechanism by which the universe updates itself, and they quietly assume unlimited memory and zero-cost change.

Tension Theory starts from the opposite end: any system that evolves must store state, update it locally, and pay a cost to do so. The single primitive is tension — the constrained informational difference between neighboring states. Tension is both the pressure to change and the price of changing.

Everything else — time, space, causality, particles, fields, probability, even measurement — falls out as what a finite, local, tension-driven system inevitably looks like from within.

02 — THE RULES

Ten postulates. Nothing else.

The whole theory rests on these assumptions — finite memory, local interaction, costly change. No continuity, probability, or geometry is put in by hand.

P1 Finite Memory

Any evolving system has finite capacity to store state. No lossless or infinite memory exists.

P2 Local State

State is defined locally. A system sees only adjacent or coupled states, never a global configuration.

P3 Cost of Update

Every state transition has a non-zero informational cost, expressed as tension. Zero-cost change is impossible.

P4 Tension as Primitive

Tension — constrained informational difference between states — is the fundamental quantity governing evolution.

P5 Discrete Updates

All evolution occurs in discrete steps. Continuity is an emergent approximation.

P6 Irreversibility

Updates are generally irreversible. Perfect reversal would require infinite memory.

P7 Relational Structure

No absolute space or background geometry. Structure arises from relations between states.

P8 Emergent Time

Time is not fundamental — it is the ordering of irreversible updates under memory constraints.

P9 Observation as Coupling

Observation is a physical interaction that redistributes tension. No external observer, no special measurement rule.

P10 Stability via Constraint

Persistent forms are configurations where tension gradients locally balance. Instability is unresolved tension.

03 — EMERGENCE

Nothing fundamental is added. Familiar physics falls out.

Seven things we usually treat as primitives turn out to be regularities of the update process.

Time
= ordered irreversibility

Updates cost, overwrite prior state, and cannot be undone — so the system acquires a natural arrow. Time is what accumulated, non-reversible change feels like.

Space
= stable relational graph

Nodes that keep stable, low-tension connections form neighborhoods. Distance is relational — counted in updates and propagation delay, not meters.

Causality
= dependency under locality

A state causes another only through adjacency, a tension gradient, and an update that depends on it. No action at a distance — apparent non-locality is stored correlation.

Particles
= stable tension loops

Localized configurations that circulate tension internally and resist dispersion. Identity is a maintained pattern, not a substance. Creation and annihilation are formation and collapse.

Fields
= large-scale tension gradients

Not entities but statistical regularities: tension varying smoothly across many nodes. Field equations are coarse-grained descriptions of aggregate update dynamics.

Probability
= incomplete local knowledge

Finite memory and local access make full configurations unknowable. Randomness reflects information loss, not intrinsic indeterminism.

Observation
= constrained coupling

When observer and target interact, tension redistributes and both change; alternatives collapse because memory is overwritten. Collapse is just an update.

04 — PREDICTIONS

Where it could break.

The framework is falsifiable in principle. If any of these fail, the theory fails.

P1
No perfect reversibility

Fundamental lower bounds on reversibility beyond standard thermodynamics, observable in sufficiently isolated, high-precision systems.

P2
All influence is local

No experiment can use entanglement to transmit information without a mediating interaction history — even in principle.

P3
Memory-limited precision

At small enough scales or long enough durations, physical constants show discretization or drift consistent with bounded state representation.

P4
Observation has a cost

Regimes exist where measurement back-action exceeds standard quantum limits — driven by memory overwrite, not uncertainty relations.

P5
Continuum models break

When update granularity becomes comparable to system scale, continuum-based predictions deviate — without invoking quantum gravity.

P6
Everything is simulable

No physically realizable process requires non-local or infinite-memory computation. The universe is executable.

05 — STATUS

Incomplete by design. Built to be tested — and broken.

v0.1 is structural, not quantitative. The tension function needs a concrete form, the mapping to known constants is open, and everything must ultimately survive simulation. That's the point: predictions come from running the model, not solving idealized equations.
